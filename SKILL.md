# crap4rust

Use this command as the Rust quality gate in SwarmForge.

## Install

```bash
python -m pip install --upgrade "git+https://github.com/lukasa1993/crap4rust.git"
```

## Verify

Read `README.md`, inspect `crap4rust --help`, and run the command from the project root. Keep generated reports under `target/` and do not commit them.
